# Архитектурные решения — Одиссея Гомера

### Статический генератор на чистом Python (без Flask, без зависимостей)
Почему: сайт — это статика, сервер не нужен; проще и бесплатно хостить на GitHub Pages.
Отвергли: Flask/сервер (избыточно для статики), Jekyll/SSG-фреймворк (лишние зависимости и
магия сборки — хотелось голый `python3 build.py`).

### Контент отделён от вёрстки: content.py → build.py → docs/
Почему: править текст разбора, не трогая HTML; единый каркас страниц в одном месте (`layout()`).
`docs/` — генерируемая папка (build делает `rmtree` + пересборку), руками не редактируется.

### Хостинг — GitHub Pages из папки docs/ ветки main
`.nojekyll` (пишется build-ом) отключает обработку Jekyll — файлы раздаются как есть.
Push в `main` → деплой за ~минуту. При необходимости бэкенда — только serverless, не VPS.

### Отдельность от wb_sales (2026-07-01)
Проект намеренно самостоятельный: свой CLAUDE.md, свой brain/, своя память Claude.
Никакого общего кода или общей памяти с другими репозиториями.

### Две поэмы — в одном репозитории, а не в двух (2026-08-03)
«Илиаду» начали как отдельный проект, но выкатывать решили на этот же сайт. Выбрали слияние
в один репозиторий: одна команда `python3 build.py` собирает обе поэмы, один коммит, один push,
нечему рассинхронизироваться.
Отвергли вариант «два репозитория + шаг публикации»: там сборка «Одиссеи» (`rmtree docs/`)
стирала бы скопированную папку «Илиады», публикация шла бы в два шага и в два git-репозитория —
лишний источник ошибок ради умозрительной раздельности.

### Данные — по файлу на поэму, генератор один
`content_odyssey.py` и `content_iliad.py` имеют одинаковую структуру (META, PARTS, CHARACTERS,
THEMES, SONGS), поэтому `build.py` обходит их единообразно через список `BOOKS`. Добавить третью
поэму — это новый `content_*.py` плюс одна запись в `BOOKS`.

### Имя репозитория и адрес сайта не меняли
Репозиторий остался `odyssey-of-homer`, хотя поэм теперь две. Переименование в `homer` дало бы
более честный адрес, но GitHub не гарантирует редирект Pages после переименования — уже
разошедшиеся ссылки могли бы отвалиться. Косметика не стоит битых ссылок.

### Старые адреса песен сохранены редиректами
Песни «Одиссеи» переехали с `song-NN.html` на `odyssey-song-NN.html` ради симметрии с «Илиадой».
Чтобы старые ссылки не умерли, `build.py` генерирует на прежних адресах заглушки с
`meta refresh` + `rel=canonical` (флаг `"legacy": True` у поэмы).
