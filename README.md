# Гомер и Вергилий — «Одиссея», «Илиада» и «Энеида», разбор по песням

Маленький **статический сайт**: краткое описание сюжета и главных моментов трёх поэм
античного эпоса — по всем песням каждой, — плюс режим чтения с полным текстом (пока для
«Одиссеи» и «Илиады»). Отдельный проект, никак не связанный с другими репозиториями.

Стек намеренно простой — **без Flask, без сервера, без зависимостей**: чистый Python-генератор
собирает HTML, который можно открыть локально или бесплатно захостить как статику.

**Живой сайт:** https://rin900work-png.github.io/odyssey-of-homer/

## Структура

```
content_odyssey.py  — данные разбора «Одиссеи»: мета, 3 части, герои, темы, 24 песни
content_iliad.py    — то же для «Илиады»: 3 части, 24 песни
content_aeneid.py   — то же для «Энеиды»: 2 части, 12 песен
build.py            — генератор: читает content_*.py + texts/ → собирает HTML в docs/
texts/odyssey/      — полный текст «Одиссеи», song-01..24.txt (один стих на строку)
texts/iliad/        — полный текст «Илиады»
static/style.css    — стили (пергамент; синь у «Одиссеи», бронза у «Илиады», пурпур у «Энеиды»)
static/img/<поэма>/ — иллюстрации (общественное достояние)
tools/              — вспомогательные скрипты (скачивание текстов и картинок)
docs/               — СГЕНЕРИРОВАННЫЙ сайт
```

Хочешь поправить текст разбора — правишь нужный `content_*.py` и пересобираешь. Менять HTML
руками не нужно.

## Сборка

Нужен только Python 3 (стандартная библиотека, никаких `pip install`):

```bash
python3 build.py
```

Команда заново собирает папку `docs/` — сразу все три поэмы. Посмотреть локально — открыть
`docs/index.html` в браузере.


## Композиция

**«Одиссея»**

- **I. Телемахия** (песни 1–4) — Итака без Одиссея, путешествие Телемаха.
- **II. Странствия** (5–12) — феаки и рассказ Одиссея: киклоп, Цирцея, царство мёртвых, сирены.
- **III. Возвращение и месть** (13–24) — узнавания, лук, расправа над женихами, примирение.

**«Илиада»**

- **I. Гнев** (песни 1–9) — ссора с Агамемноном, поражения ахейцев, отвергнутое посольство.
- **II. Битва у кораблей и Патроклия** (10–18) — штурм стены, гибель Патрокла, новый щит.
- **III. Возмездие и выкуп** (19–24) — гибель Гектора, погребение Патрокла, выкуп тела.

**«Энеида»**

- **I. Странствия** (песни 1–6) — буря, гибель Трои, скитания, Дидона, сошествие в Аид;
  построена по образцу «Одиссеи».
- **II. Война в Лации** (7–12) — союзники, битвы, поединок Энея с Турном; построена по
  образцу «Илиады».

## Режим чтения

На каждой странице песни «Одиссеи» и «Илиады» есть раскрывающийся блок с её полным текстом:
«Одиссея» — перевод **В. А. Жуковского** (12 106 стихов), «Илиада» — перевод
**Н. И. Гнедича** (15 689 стихов). Оба перевода — **общественное достояние**,
источник — Викитека (ru.wikisource.org). Нумерация стихов сверена с канонической.

У «Энеиды» режима чтения пока нет: единственный полный дореволюционный (PD) перевод —
И. Г. Шершеневича, 1868 — на Викитеке не расшифрован для песен I и II (самых известных —
Дидоны и падения Трои), есть только сканы. Как только найдётся чистый источник текста для
всех 12 песен, режим чтения можно будет добавить так же, как у двух других поэм.

## Иллюстрации

К песням и персонажам «Одиссеи» подобраны картины и гравюры в **общественном достоянии**
(Wikimedia Commons): Тёрнер, Бёклин, Уотерхаус, Фюссли, Дрейпер, Климт, Давид, Кауфман и др.
Под каждой — подпись с автором и названием. Файлы лежат в `static/img/<поэма>/`, привязка —
в конце соответствующего `content_*.py` (списки `_SONG_IMG` и `_CHAR_IMG`). У «Илиады» и
«Энеиды» иллюстрации пока не подобраны (список персонажей и песен уже готов принять их).

## Как опубликовать (GitHub Pages)

Сайт раздаётся через GitHub Pages из папки `docs/` ветки `main`.

```bash
python3 build.py        # пересобрать docs/
git add -A
git commit -m "обновил разбор"
git push                # GitHub Pages подхватит изменения за ~минуту
```

## Другие варианты хостинга

Сайт — статика, сервер не нужен. Папку `docs/` можно так же раздать на Cloudflare Pages,
Netlify или Vercel. Понадобится бэкенд — брать serverless (Cloudflare Workers / Vercel
functions), а не выделенный сервер.
